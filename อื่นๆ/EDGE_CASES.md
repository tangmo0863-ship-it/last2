# Known Edge Cases — ต่อโมดูล (v16)

รวมเคสขอบที่เจ้าของแต่ละโมดูลต้องรู้และทดสอบ ทุกเคสตรวจจากโค้ดจริง + ข้อมูลจริง
สถานะ: ✅ จัดการแล้ว · ⚠️ จัดการแล้วแต่ต้องเขียนเป็นข้อจำกัด · 🔍 ทางทฤษฎี ยังไม่เจอในข้อมูล

**หุ้นที่ต้องเปิดดูทุกครั้งที่แก้โค้ด:** HANA, JMART (ขาดทุน) · TRUE (ควบรวม) · DELTA (ราคาสูงกว่าพื้นฐานมาก) · THCOM (กำไรต่ำมาก)

## หลักการกลาง (ใช้ทุกโมดูล)

| เคส | วิธีจัดการ |
|---|---|
| ค่าจากสูตรเป็น `None` แล้วกลายเป็น `NaN` หลังบันทึก SQLite | หน้าจอต้องแสดงผ่าน `safe()` / `fmt_ratio()` เท่านั้น ห้าม `stock_info.get('key','-')` ตรง ๆ (เคยทำให้ P/E ขึ้น `nanx`) |
| ข้อมูลไม่พอ | คืน `None` และแสดง **N/A** พร้อมเหตุผล — **ห้ามแทนด้วยค่าสมมติ** (เดิมมี ROE 10%, ราคา 10 บาท, AI accuracy 75%, AI score 50 — ลบออกหมดแล้ว) |
| คะแนนถูกบีบขั้นต่ำ (25/30) จนหุ้นแย่ดูไม่แย่ | ✅ เลิกบีบแล้ว ใช้ช่วง 0–100 ตามสูตร |
| แก้สูตรแล้วเว็บยังแสดงตัวเลขเก่า | ✅ เปลี่ยน `CALC_VERSION` ใน `calculate_scores.py` แอปจะคำนวณ DB ใหม่เอง |
| `common.py` (หน้าจอ) เวอร์ชันเก่าไม่มี `render_chart_note` | ✅ หน้าจอ import แบบมี fallback — แอปไม่พัง แค่ไม่แสดงแถบ ⓘ |
| ชื่อไฟล์ซ้ำ (`fair_value.py` ฯลฯ อยู่ทั้งใน `pages_content/` และ `calculate_modules/`) | วางผิดโฟลเดอร์ = แอปพัง เช็คบรรทัดแรก: ไฟล์หน้าจอมี `import streamlit` |
| ไฟล์ดาวน์โหลดซ้ำชื่อ `xxx (1).py` | Python ไม่ใช้ไฟล์นี้ `rebuild_database.py` จะแจ้งเตือนและหยุด |

## 📂 ข้อมูล (Dataset / import_data)

| เคส | สถานะ |
|---|---|
| คอลัมน์ ROE/ROA ใน CSV ขัดกับกำไรจริง (HANA 2025 ขาดทุนแต่ ROE +2.51%) | ✅ `import_data.py` คำนวณ ROE = กำไรสุทธิ ÷ ส่วนผู้ถือหุ้น, ROA = กำไรสุทธิ ÷ สินทรัพย์ ค่าเดิมเก็บที่ `roe_reported` / `roa_reported` |
| แถว "วันหยุดปลอม" (Volume = 0, High = Low = Close) 403 แถว | ✅ ตัดออกใน Risk และ Beta · ⚠️ AI และ Entry Timing ยังใช้แถวเหล่านี้ |
| ADX ในไฟล์ราคาเดิม (2023-25) ของ CCET/JMART/THCOM เพี้ยน 1–3 จุด | ✅ ไฟล์ 10 ปีจาก `fetch_price_history.py` คำนวณ ADX ใหม่จาก High/Low ชุดเดียวกัน |
| ตัวกรองวันที่เดิม `>= 2023-01-01` ตัดไฟล์ 10 ปีเหลือ 3 ปีโดยไม่เตือน | ✅ ตั้งช่วงที่ `PRICE_START_DATE` / `PRICE_END_DATE` ใน `import_data.py` |
| Max Drawdown ใน `stock_risk_metrics.csv` เดิม = −29.36% ทุกหุ้น / Beta ไม่รู้ที่มา | ✅ แทนด้วยไฟล์จาก `compute_beta.py` (ต้นฉบับเก็บที่ `Dataset/_archive/`) |
| Yahoo ไม่ส่งข้อมูลดัชนี SET | ⚠️ `compute_beta.py` ใช้ TDEX (ETF อ้างอิง SET50) แทนอัตโนมัติ หรือใช้ `--index-file` |
| รันสคริปต์ใน Colab แล้ว error `-f kernel.json` | ✅ สคริปต์ใช้ `parse_known_args` แล้ว หรือใส่ `sys.argv = ["x"]` บนสุดของช่อง |

## ⚖️ Fair Value

| เคส | สถานะ |
|---|---|
| EPS ติดลบ (HANA, JMART) | ✅ P/E = N/A ใช้ DCF อย่างเดียว ป้ายแสดง "DCF เท่านั้น" |
| FCF ติดลบ (THCOM) | ✅ DCF = N/A ใช้ P/E อย่างเดียว |
| ขาดทุนทั้ง EPS และ FCF | ✅ `valuation_status = NOT_RATED` คะแนน 0 · หน้าจอแสดง NOT RATED (เดิมแต่งราคา × 1.1) |
| ไม่มีข้อมูลเลย | ✅ `valuation_score = None` (ไม่ถูกนับว่าแพงที่สุด) |
| หนี้สุทธิเดิมรวมเจ้าหนี้การค้า (DELTA = 79% ของหนี้สิน) | ✅ หนี้สุทธิ = หนี้สินรวม − เจ้าหนี้การค้า − เงินสด |
| FCF สูงกว่ากำไรมาก (TRUE 6 เท่า, JMART 18.6 เท่า) | ⚠️ ธง `fcf_quality_warning` เมื่อ > 1.5 เท่า — สาเหตุ: ไม่มีข้อมูลค่าเช่าโครงข่าย/ใบอนุญาตที่อยู่ในกระแสเงินสดจัดหาเงิน |
| DCF ด้วย WACC จาก CAPM ให้ค่าพุ่ง (ADVANC 983, TRUE 63) | ⚠️ จึงคง WACC เดิมของทีม · Rf ไทย 1.66% ทำให้ WACC − g แคบมาก |
| การ์ด Market Expectation: DELTA ROE ที่ราคาคาดหวัง 229.5% | ⚠️ ไม่ใช่บั๊ก — P/B 22 เท่า + Ke 12.4% สะท้อนความคาดหวังการเติบโต ไม่ใช่ ROE ตามตัวอักษร |
| การ์ด Market Expectation: ส่วนผู้ถือหุ้นติดลบ / ไม่มี Beta | ✅ ไม่แสดงการ์ด / ใช้ Beta 1.0 พร้อมหมายเหตุ |
| ราคาประเมินดิบเกิน 65%–185% ของราคาตลาด | ✅ คะแนนใช้ค่าที่บีบ แต่ตัวเลข Fair Value ที่แสดงเป็นค่าดิบ + คำเตือน |
